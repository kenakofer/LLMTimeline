# Archive — the original hand-drawn timeline

`drawing.svg` (Inkscape source) and `drawing.png` (export) are the original hand-drawn
Frontier Large Language Model Timeline, maintained from 2023 to May 2025. The final
version is marked `v2025-05-24`.

It was superseded in July 2026 by the data-driven site in `../site/`, which is generated
from the curated dataset in `../data/`. These files are kept for provenance: the published
URL pointed at this render, and the work has been shared under a CC licence.

The drawing tracked ~32 model cards with parameter counts, context windows, in/out pricing,
and feature badges (open weights, image upload/generation, web browsing, chain-of-thought,
realtime voice). Release dates were largely implied by vertical position rather than stated —
only 17 explicit date labels exist for 32 cards. That limitation is what prompted the rework.

Note that the model names, prices, and context values here reflect what was accurate as of
May 2025 and are **not** maintained. Use `../data/` as the current source of truth.
