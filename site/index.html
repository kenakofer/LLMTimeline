Frontier Large Language Model Timeline

When frontier models appeared, became available, and were retired. Every date is sourced; uncertain dates are drawn as uncertain rather than rounded into false precision.

Labs

On uncertainty. Public release and deprecation dates come from first-party documentation and are usually exact. Internal dates are not: labs describe the gap between internal and public availability only vaguely, and independent evaluators such as METR work from attested windows rather than dates. Where a model has no sourced internal date, the bar simply starts at the first known event and a faded ellipsis marks the unknown period — its width carries no meaning. Hover any segment to read the reasoning behind an estimated date.

Data lives in data/ as YAML, one file per lab, with a source URL per datapoint. Superseded the original hand-drawn version (2023–2025).
