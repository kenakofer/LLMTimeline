Prototype: one box per model, placed at release

Each box is a model, placed at its first public appearance. Busy years get more horizontal room: the time axis is stretched by release count, so gridline spacing varies. The thin line after a box is its lifespan, which ends where the model was retired. Hover a box to trace where it came from and what came from it.
